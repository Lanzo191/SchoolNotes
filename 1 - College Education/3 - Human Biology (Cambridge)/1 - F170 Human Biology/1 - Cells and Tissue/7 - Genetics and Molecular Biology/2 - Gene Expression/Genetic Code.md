The **Genetic Code** is the set of rules used by living cells to translate information encoded within genetic material into [[Proteins]].

## Structure: Characteristics

### 1. Triplet Nature
- The code is read in groups of three bases called **[[Codon]]**.
- 64 possible [[Codon]] (4^3) for 20 [[Amino Acids]].

### 2. Degenerate (Redundant)
- Multiple [[Codon]] can code for the same amino acid (e.g., GGU, GGC, GGA, and GGG all code for Glycine).
- **Benefit**: Provides protection against some point mutations.

### 3. Non-overlapping
- Each base is part of only one [[Codon]]; the "reading frame" moves three bases at a time.

### 4. Universal
- Almost all organisms use the same code, which is strong evidence for a common evolutionary origin.

### 5. Start and Stop Codons
- **AUG**: The universal start [[Codon]] (codes for Methionine).
- **UAA, UAG, UGA**: Stop [[Codon]] that terminate [[Translation]].

## Function
- Provides the "dictionary" that allows the 4-letter [[Nucleotides]] alphabet to be converted into the 20-letter amino acid alphabet.

## Clinical Relevance
- **Frameshift Mutations**: Inserting or deleting a base shifts the entire reading frame, usually resulting in a non-functional protein.

## Summary
The genetic code is a universal, degenerate, and non-overlapping system that ensures the accurate [[Translation]] of genetic sequences into functional [[Proteins]].


To understand synthesis, you must understand the "Language" used to build [[Proteins]].

## Characteristics of the Code
1. **Triplet**: Three bases (one [[Codon]]) = one amino acid.
2. **Non-Overlapping**: Each base is only part of one [[Codon]]. A mutation in one base only affects one [[Codon]].
3. **Degenerate**: There are 64 possible [[Codon]] but only 20 [[Amino Acids]]. This provides a "buffer" against mutations (e.g., if CCU and CCC both code for Proline, a mutation in the third base has no effect).
4. **Universal**: The same code is used by bacteria, plants, and humans. This is why we can put a human [[Insulin]] gene into a bacteria and the bacteria can "read" it and make human [[Insulin]] for us.
