**Pearson’s r** is a **parametric** test for a **correlation** using **[[Interval Data]]**.

## When to Use
1. **Goal**: Correlation.
2. **Data**: Interval.
3. **Parametric Criteria**: Data must be normally distributed with similar [[Variance]].

---

## Expansive Worked Scenario
**Research Aim**: To see if there is a correlation between height (cm) and shoe size.
**Data**: 20 participants.

### Step 1: Observed Value ($r$)
- After conducting the parametric analysis on a computer, the researcher found an **Observed Value of $r = 0.65$**.
- This indicates a **strong positive correlation**.

### Step 2: Calculate Degrees of Freedom ($df$)
- $df = N - 2 = 20 - 2 = \mathbf{18}$

### Step 3: Compare to Critical Value
- For $df=18$ at $p \leq 0.05$ (two-tailed), the **Critical Value is 0.444**.

### Conclusion
"The observed value of $r=0.65$ is **greater than** the critical value of 0.444. Therefore, the results are **significant** at $p \leq 0.05$. We reject the Null Hypothesis and conclude there is a significant positive correlation between height and shoe size."
