**Inferential Statistics** allow psychologists to draw conclusions about whether findings are due to **chance** or represent a real effect in the population.

## Core Concepts

| Concept | **Explanation** |
| :--- | :--- |
| **Significance** | A result is significant if it is unlikely to have occurred by chance (usually **$p \leq 0.05$**). |
| **Observed Value** | The number you calculate when performing the statistical test. |
| **Critical Value** | The number you look up in a table. If your observed value meets the specific test's rule (e.g., $\leq$ CV), it is significant. |
| **Probability ($p$)** | The likelihood that the results are due to chance. $p=0.05$ means there is a 5% chance the result is a fluke. |

---

## Choosing the Right Test
Selection depends on the **Goal** (Difference vs Correlation), the **Design** (Independent vs Related), and the **Data Level** (Nominal, Ordinal, or Interval).

- **[[Choosing a Statistical Test]]**: A complete guide and decision table.

## The Statistical Tests

### 1. Nominal Data Tests (Categories)
- **[[Sign Test]]**: Difference, Related design.
- **[[Chi-Square]]**: Difference or Association, Independent design.
- **[[Binomial Test]]**: Single sample, testing against a fixed probability.

### 2. Ordinal Data Tests (Ranked)
- **[[Mann-Whitney U]]**: Difference, Independent design.
- **[[Wilcoxon T]]**: Difference, Related design.
- **[[Spearmans Rho]]**: Correlation / Relationship.

### 3. Interval Data Tests (Measurements)
- **Unrelated t-test**: Difference, Independent design.
- **Related t-test**: Difference, Related design.
- **Pearson’s r**: Correlation / Relationship.

## Common Exam Requirements
In the OCR Psychology exam, you are often asked to:
1. **Identify** the correct test for a given scenario.
2. **Justify** why that test was chosen (referencing Goal, Design, and Data).
3. **Compare** an Observed Value to a Critical Value and state if it is significant.
4. **Calculate** the **[[Sign Test]]** by hand.
