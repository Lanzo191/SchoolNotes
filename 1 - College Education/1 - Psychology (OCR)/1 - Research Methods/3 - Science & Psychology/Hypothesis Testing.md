## Overview -
**Hypothesis Testing** is the process of using statistical methods to determine if there is enough evidence in a sample of data to infer that a certain condition is true for the entire population.

## The Process -

1.  **Theory:** Start with a general idea (e.g., "Sleep improves memory").
2.  **Prediction:** Create a specific **Alternate Hypothesis** (H₁) and a **[[Null Hypothesis]]** (H₀).
3.  **Research:** Conduct the study and collect data.
4.  **Statistics:** Run a statistical test to find the **[[P-Value]]**.
5.  **Conclusion:** 
    *   If p ≤ 0.05: Reject the Null and **Accept the Alternate**.
    *   If p > 0.05: Accept the Null and **Reject the Alternate**.

---

## Why is it Scientific? -
Hypothesis testing allows psychology to move beyond "common sense" or guesses. It provides a formal, objective way to see if an effect is **Significant** (real) or just a result of **Chance** (luck).
