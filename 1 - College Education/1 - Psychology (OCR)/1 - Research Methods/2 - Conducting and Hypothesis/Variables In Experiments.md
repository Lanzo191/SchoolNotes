# Independent Variable (IV) -  
The variable that is **manipulated** by the researcher to observe its effect on the [[Dependent Variable]].  

### Strengths -  
- Clearly defines what is being tested  
- Allows cause-and-effect conclusions in experiments  

### Weaknesses -  
- Only applicable in experimental research  
- Must be operationalised precisely  

### Examples -  
- Type of beverage consumed (coffee, tea, water) affecting memory recall  
- Amount of revision time affecting test scores  

---

# Dependent Variable (DV) -  
The variable that is **measured** to see the effect of the IV.  

### Strengths -  
- Provides measurable outcomes  
- Can be quantitative or qualitative  

### Weaknesses -  
- Can be influenced by extraneous variables if not controlled  
- Measurement errors may affect results  

### Examples -  
- Memory recall score on a test  
- Number of correct answers in a quiz  
- Level of anxiety measured on a questionnaire  

---

# Controlled Variables (CV) -  
Variables that are **kept constant** to ensure they do not affect the DV.  

### Strengths -  
- Reduces confounding variables  
- Increases internal validity  

### Weaknesses -  
- Hard to control every variable in natural settings  
- Can make experiments artificial  

### Examples -  
- Same room temperature for all participants  
- Same test paper for all students  
- Same duration of exposure to a stimulus  

---

# Extraneous Variables (EV) -  
Variables other than the IV that **might affect the DV** if not controlled.  

### Strengths -  
- Awareness helps improve experimental design  
- Can be measured or controlled to improve validity  

### Weaknesses -  
- Difficult to identify all possible extraneous variables  
- Can reduce reliability if uncontrolled  

### Examples -  
- Participants’ mood or fatigue during a test  
- Noise in the environment  
- Prior knowledge affecting test performance  

---

# Confounding Variables -  
A type of extraneous variable that **systematically affects the DV**, making it impossible to determine the true effect of the IV.  

### Strengths -  
- Identifying confounding variables improves experimental design  
- Helps interpret results accurately  

### Weaknesses -  
- Can invalidate results if not controlled  
- May be difficult to identify  

### Examples -  
- If one group in a memory test is older than the other, age could confound the results  
- Using different rooms for each group, where lighting affects performance
