# Control -  
Control in psychology refers to the methods used to **minimise the influence of [[Extraneous Variables]]** so that changes in the [[Variables In Experiments|dependent variable (DV)]] can be attributed to the [[Variables In Experiments|independent variable (IV)]].  

### Key Points -  
- Helps establish **[[Cause and Effect]]** in experiments.  
- Can involve **holding variables constant**, using **randomisation**, or **counterbalancing**.  
- Reduces the risk of **[[Confounding Variables]]** affecting results.  
- Improves **internal [[Validity]]**.  

### Example -  
- In a memory experiment testing caffeine, control variables could include **same time of day, same test, same environment**, and **same sleep duration** for all participants.
