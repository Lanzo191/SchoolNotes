## Index: Levels of Data -

To conduct psychological research, you must understand the different ways that data can be collected and categorised.

---

## 1. Quantitative vs Qualitative -
*   **Quantitative Data:** Numerical data that can be measured and analysed statistically.
*   **Qualitative Data:** Descriptive, word-based data providing depth and insight into thoughts and feelings.
*   *Links:* [[Quantitative Data]] | [[Qualitative Data]]

## 2. Primary vs Secondary -
*   **Primary Data:** Data collected first-hand by the researcher specifically for the current study.
*   **Secondary Data:** Data that already exists, collected by someone else for another purpose (e.g., government statistics).
*   *Links:* [[Primary Data]] | [[Secondary Data]]

## 3. Discrete vs Continuous -
*   **Discrete Data:** Data that can only take specific values (e.g., number of children).
*   **Continuous Data:** Data that can take any value within a range (e.g., height, weight).
*   *Links:* [[Discrete Data]] | [[Continuous Data]]

## 4. Levels of Measurement -
*   **Nominal Data:** Data in separate categories (e.g., eye colour).
*   **Ordinal Data:** Data that can be ranked or ordered, but with unequal intervals (e.g., place in a race).
*   **Interval Data:** Precise measurements with equal intervals but no true zero (e.g., temperature in Celsius).
*   **Ratio Data:** Precise measurements with equal intervals and a **true zero** (e.g., weight, time).
*   *Links:* [[Nominal Data]] | [[Ordinal Data]] | [[Interval Data]] | [[Ratio Data]]
