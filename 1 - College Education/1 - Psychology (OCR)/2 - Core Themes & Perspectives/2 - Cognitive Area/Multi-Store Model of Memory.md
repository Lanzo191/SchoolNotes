## Multi-Store Model of Memory (Atkinson & Shiffrin, 1968)

## Overview
The Multi-Store Model (MSM) is an influential model of memory that proposes memory consists of three separate, interacting stores: the Sensory Register (SR), Short-Term Memory (STM), and Long-Term Memory (LTM). Information flows between these stores in a linear fashion.

## Components of the MSM

### 1. Sensory Register (SR)
-   **Function:** Holds information detected by the senses for a very brief period.
-   **Capacity:** Very large (potentially unlimited).
-   **Duration:** Very short (e.g., visual information (iconic) lasts less than 0.5 seconds; auditory information (echoic) lasts 2-4 seconds).
-   **Input:** Receives information directly from sensory organs.
-   **Transfer:** If [[Attention]] is paid to sensory information, it is passed to the STM. Otherwise, it decays or is replaced by new information.

### 2. Short-Term Memory (STM)
-   **Function:** Temporarily holds a limited amount of information that we are actively attending to.
-   **Capacity:** Limited (around 7 +/- 2 items, according to Miller's (1956) magic number). Can be increased by **chunking**.
-   **Duration:** Short (around 18-30 seconds, unless rehearsed).
-   **Input:** Receives information from the SR (via attention) and LTM (for retrieval/working on).
-   **Transfer:** If information is rehearsed (maintenance rehearsal), it can be kept in STM. Elaborative rehearsal transfers information to LTM. Without rehearsal, information is lost through decay or displacement.

### 3. Long-Term Memory (LTM)
-   **Function:** Stores information for extended periods, from minutes to a lifetime.
-   **Capacity:** Potentially unlimited.
-   **Duration:** Potentially unlimited (lifetime).
-   **Input:** Information is transferred from STM through **elaborative rehearsal**.
-   **Retrieval:** Information can be retrieved from LTM back into STM for use.

## Key Processes

-   **Attention:** The process of focusing on specific sensory information, allowing it to pass from the SR to STM.
-   **Encoding:** The way information is converted into a form that can be stored in memory (e.g., acoustically in STM, semantically in LTM).
-   **Rehearsal:**
    -   **Maintenance Rehearsal:** Repeating information to keep it in STM.
    -   **Elaborative Rehearsal:** Linking new information to existing information in LTM, leading to deeper processing and more effective transfer to LTM.
-   **Retrieval:** The process of accessing stored information from LTM and bringing it back into STM (conscious awareness).
-   **Decay:** The fading of memory traces over time, especially in SR and STM if not rehearsed.
-   **Displacement:** New information entering STM can push out older information if capacity is reached.

## Evaluation of the Multi-Store Model

### Strengths
-   **Influential:** The first comprehensive model of memory, highly influential and generated much research.
-   **Evidence for Separate Stores:** Supported by research showing distinct capacity and duration for STM and LTM (e.g., Peterson & Peterson for STM duration, Baddeley for encoding).
-   **Explains Amnesia:** Helps understand cases of amnesia where one store (e.g., STM) is impaired while another (e.g., LTM) remains intact.

### Weaknesses
-   **Oversimplified LTM:** MSM suggests LTM is a single, unitary store. Research (e.g., Tulving's (1972) distinction between episodic, semantic, and procedural memory) shows LTM is more complex.
-   **Oversimplified STM:** MSM suggests STM is a passive, unitary store. The [[Working Memory Model]] (Baddeley & Hitch) proposes a more active, multi-component STM.
-   **Overemphasis on Rehearsal:** Elaborative rehearsal is crucial for LTM, not just maintenance rehearsal. The model doesn't fully explain how information can transfer to LTM without conscious rehearsal.
-   **Passive Process:** Views memory as a passive, linear flow of information, whereas memory is now understood as a more active and constructive process.
-   **Lack of Ecological [[Validity]]:** Much of the supporting research uses artificial lab tasks (e.g., recalling consonant trigrams or word lists) that lack relevance to real-life memory.
